# Architecture

This document describes the architecture of the dotfiles repository.

## Overview

The repo uses a flake-based NixOS configuration with:
- Modular NixOS system configuration
- home-manager for user environment
- Composable profiles
- Reusable module system

## lib/ Framework

The `lib/default.nix` provides helper functions:

```nix
{
  mkUser =
    { username
    , description ? ""
    , modules ? [ ]
    }:
    {
      inherit username modules description;
    };
}
```

### mkUser

Creates a user configuration with username, description, and home-manager modules.

```nix
mkUser {
  username = "alice";
  description = "Alice User";
  modules = [ ./home/alice/shell.nix ];
}
```

## Module System

### NixOS Modules

Location: `modules/nixos/`

Structure:
```
modules/nixos/
├── default.nix    # Aggregates all nixos modules
├── niri.nix      # Niri Wayland compositor
└── *.nix         # Additional modules
```

Each module declares options and provides configuration:

```nix
{ lib, config, pkgs, ... }:

{
  options.myModule.enable = lib.mkEnableOption "my module";

  config = lib.mkIf config.myModule.enable {
    environment.systemPackages = [ pkgs.myPackage ];
  };
}
```

Toggle in host config:
```nix
myModule.enable = true;
```

### Home Manager Modules

Location: `modules/home/`

Structure:
```
modules/home/
└── default.nix    # Aggregates home modules
```

Option naming: `lucy.<moduleName>.enable`

```nix
{ lib, config, ... }:

{
  options.lucy.myModule = {
    enable = lib.mkEnableOption "my user module";
  };

  config = lib.mkIf config.lucy.myModule.enable {
    home.packages = [ pkgs.myPackage ];
  };
}
```

Toggle in home config:
```nix
lucy.myModule.enable = true;
```

## Profiles

Profiles are composable collections of modules.

### base.nix

Base system configuration with common settings:
- Locale: en_US.UTF-8
- Editor: vim
- Printing: CUPS
- User: lucy with wheel + networkmanager groups

### desktop.nix

Extends base with desktop features:
- GNOME desktop environment
- GDM display manager
- PipeWire audio
- X server with US keymap

## Host Configuration

Hosts are defined in `hosts/<hostname>/`:

```
hosts/p50/
├── default.nix              # Main system config
└── hardware-configuration.nix  # Hardware-specific
```

The `hardware-configuration.nix` is auto-generated by `nixos-generate-config` and contains:
- Boot kernel modules
- File system mounts
- LUKS devices
- CPU microcode

## flake.nix Structure

```nix
{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/24.11";
    home-manager.url = "github:nix-community/home-manager";
    home-manager.inputs.nixpkgs.follows = "nixpkgs";
  };

  outputs = { nixpkgs, home-manager, ... }:
    {
      nixosConfigurations.p50 = nixpkgs.lib.nixosSystem {
        system = "x86_64-linux";
        modules = [ ./hosts/p50 ];
      };

      homeConfigurations."lucy@p50" = home-manager.lib.homeManagerConfiguration {
        pkgs = nixpkgs.legacyPackages.x86_64-linux;
        modules = [ import ./home/lucy ];
      };
    };
}
```

## Design Decisions

1. **nixpkgs 24.11**: Stable release used due to bugs in nixos-unstable
2. **No specialArgs in nixosSystem**: Avoids shadowing nixpkgs.lib
3. **Enable options on modules**: Allows toggling features without code changes
4. **Profiles import modules**: Reuses module code across hosts
