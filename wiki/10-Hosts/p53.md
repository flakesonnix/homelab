# p53

> [!info] Profile
> **Role:** primary desktop / gaming · **HW:** ThinkPad P53 i7-9750H · **IP:** `dynamic via DHCP` (dnsmasq on mireo)
> **Deploy:** `nix run .#rebuild` (nh, preferred) or `nix run .#deploy-p53`

[[10-Hosts/Hosts-MOC|← Hosts]] · [[10-Hosts/Network|Network]] · [[20-Modules/Gaming-Stack|Gaming]] · [[40-Guides/Deploy-Rebuild|Deploy guide]]

## Features

- Niri Wayland + eww (topbar/sidebar), Stylix cyberdeck dark
- Secure Boot via lanzaboote (`/var/lib/sbctl`), suspend-then-hibernate (lid, 30 min timer on battery)
- Smartcard reader (pcscd+ccid), fingerprint reader (fprintd+PAM/GDM, enroll via Settings → Users), Tailscale, Bluetooth, Waydroid (GAPPS oneshot)
- Gaming: Steam, GameMode, Gamescope (capSysNice), MangoHud, performance governor
- Asterisk SIP PBX, audio streaming → remote tunnel sink, Deskflow keyboard/mouse sharing

## Data

- `data/hosts/p53/settings.nix` — hostname, hosts, Bluetooth, Niri users, boot params
- `data/hosts/p53/roles.nix` — `[desktop dev gaming]`
- `data/hosts/p53/module-flags.nix` — smartcard, fonts, waydroid…
- `data/hosts/p53/packages.nix`, `power.nix`, `services.nix`
- `hosts/p53/host.nix` — `applyHost` call · `hosts/p53/hardware-configuration.nix`

## Modules (flake.nix)

`audio-stream`, `fonts`, `gaming`, `gnome`, `gnome-extensions`, `niri`, `serial-getty`, `sops`, `waybar`, `hm-base`, `deskflow`, `waydroid`, `nixfleet` (package defaults, but not enabled), `lanzaboote`, `nur`, `run0-sudo-shim`. (Voice stack `asterisk`+`voip` lives on mireo.)

Details: [[20-Modules/NixOS-Modules|NixOS modules]].

## Virtualisation

Lokaler libvirtd an (`enable=true`, `qemu.swtpm.enable=true` in `data/hosts/p53/settings.nix`; `/dev/tpmrm0` vorhanden — alter 12.4-`243/CREDENTIALS`-Workaround mit `mkForce false` obsolet). virt-manager zeigt lokal `qemu:///system` + remote `qemu+ssh://root@10.8.0.1/system` (mireo, see [[10-Hosts/mireo#libvirt-virt-manager-remote-target-weg-a|mireo libvirt]]). Recovery bei `243/CREDENTIALS`: `rm /var/lib/libvirt/secrets/secrets-encryption-key` + reboot.

## Deploy

```bash
nix run .#rebuild
sudo nixos-rebuild switch --flake .#p53
nix run .#deploy-p53
```
