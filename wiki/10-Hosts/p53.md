# p53

> [!info] Profile
> **Role:** primary desktop / gaming · **HW:** currently ThinkPad P50 i7-6700HQ (`p53` hostname retained) · **IP:** `dynamic via DHCP` (dnsmasq on mireo)
> **Deploy:** `nix run .#rebuild` (nh, preferred) or `nix run .#deploy-p53`

[[10-Hosts/Hosts-MOC|← Hosts]] · [[10-Hosts/Network|Network]] · [[20-Modules/Gaming-Stack|Gaming]] · [[40-Guides/Deploy-Rebuild|Deploy guide]]

## Features

- GNOME/GDM plus SwayFX, EWM and dwl-scroll sessions; no forced default session. Niri, Plasma and the old Eww/Waybar shell are disabled.
- Stylix cyberdeck dark, Iosevka desktop/app fonts
- Intel display rendering + Quadro M1000M PRIME offload (`nvidia-offload`), proprietary legacy 580 driver
- Secure Boot via lanzaboote (`/var/lib/sbctl`), suspend-then-hibernate (lid, 30 min timer on battery)
- Smartcard reader (pcscd+ccid), fingerprint reader (fprintd+PAM/GDM, enroll via Settings → Users), Tailscale, Bluetooth, Waydroid (GAPPS oneshot)
- Gaming: Steam, GameMode, Gamescope (capSysNice), MangoHud, performance governor
- Audio streaming → remote tunnel sink; Sunshine/Moonlight streaming and OBS with virtual camera. Asterisk/VoIP lives on mireo; Deskflow is disabled.
- Firefox uses mireo's HTTPS Sync endpoint and the packaged public CA; enrollment steps in `docs/hosts.md#firefox-sync-enrollment`.

## Session shortcuts and locking

- SwayFX uses **Alt**, following the retained Niri layout: `Alt+Enter` terminal, `Alt+D` Fuzzel, `Alt+W` close, `Alt+Ctrl+Escape` lock. Idle lock: five minutes.
- dwl-scroll uses **Super**: `Super+D` built-in launcher, `Super+W` close, `Super+F` maximize column, `Super+Shift+F` fullscreen, `Super+Ctrl+Escape` manual lock. No idle locker is configured for dwl-scroll.
- dwl-scroll runs dwlb plus a tray/clock companion and reads its wallpaper from `/home/lucy/Pictures/wallpaper.webp` at runtime. Discord presence includes the focused app on p53; disable `lucy.dwlScroll.settings.discordRpc.showApp` to hide it. Full settings/keys: `docs/dwl-scroll.md`.
- EWM uses your Emacs init; `Super+L`, idle and suspend locking are scoped to `ewm.service`.

## Modules (flake.nix)

Shared modules include `dwl-scroll` and `lucy-ca`. Additional imports include `audio-stream`, `fonts`, `gaming`, `gnome`, `gnome-extensions`, `plasma`, `sunshine`, `nvidia`, `nvidia-resume`, `niri`, `ewm`, `serial-getty`, `sops`, `waybar`, `hm-base`, `deskflow`, `waydroid`, `nixfleet`, `lanzaboote` and `run0-sudo-shim`. Imports do not imply activation; Niri/Plasma/Deskflow/NixFleet are disabled here. Voice stack `asterisk`+`voip` lives on mireo.

Details: [[20-Modules/NixOS-Modules|NixOS modules]].

## Virtualisation

Lokaler libvirtd an (`enable=true`, `qemu.swtpm.enable=true` in `data/hosts/p53/settings.nix`; `/dev/tpmrm0` vorhanden — alter 12.4-`243/CREDENTIALS`-Workaround mit `mkForce false` obsolet). virt-manager zeigt lokal `qemu:///system` + remote `qemu+ssh://root@10.8.0.1/system` (mireo, see [[10-Hosts/mireo#libvirt-virt-manager-remote-target-weg-a|mireo libvirt]]). Recovery bei `243/CREDENTIALS`: `rm /var/lib/libvirt/secrets/secrets-encryption-key` + reboot.
