# x270

> [!info] Profile
> **Role:** primary desktop / gaming · **HW:** ThinkPad X270 i7-7600U · **IP:** `dynamic via DHCP` (dnsmasq on mireo)
> **Deploy:** `nix run .#rebuild` (nh, preferred) or `nix run .#deploy-x270`

[[10-Hosts/Hosts-MOC|← Hosts]] · [[10-Hosts/Network|Network]] · [[20-Modules/Gaming-Stack|Gaming]] · [[40-Guides/Deploy-Rebuild|Deploy guide]]

## Features

- Niri Wayland + eww (topbar/sidebar), Stylix cyberdeck dark
- Secure Boot via lanzaboote (`/var/lib/sbctl`), suspend-then-hibernate (lid, 30 min timer on battery)
- Smartcard reader (pcscd+ccid), Tailscale, Bluetooth, Waydroid (GAPPS oneshot)
- Gaming: Steam, GameMode, Gamescope (capSysNice), MangoHud, performance governor
- Asterisk SIP PBX, audio streaming → remote tunnel sink, Deskflow keyboard/mouse sharing

## Data

- `data/hosts/x270/settings.nix` — hostname, hosts, Bluetooth, Niri users, boot params
- `data/hosts/x270/roles.nix` — `[desktop dev gaming]`
- `data/hosts/x270/module-flags.nix` — smartcard, fonts, waydroid…
- `data/hosts/x270/packages.nix`, `power.nix`, `services.nix`
- `hosts/x270/host.nix` — `applyHost` call · `hosts/x270/hardware-configuration.nix`

## Modules (flake.nix)

`asterisk`, `audio-stream`, `fonts`, `gaming`, `gnome`, `gnome-extensions`, `niri`, `serial-getty`, `sops`, `waybar`, `hm-base`, `deskflow`, `waydroid`, `nixfleet` (package defaults, but not enabled), `lanzaboote`, `nur`, `run0-sudo-shim`.

Details: [[20-Modules/NixOS-Modules|NixOS modules]].

## Workaround

`virtualisation.libvirtd.enable = mkForce false` in `data/hosts/x270/settings.nix` — recent libvirt 12.4.0 tries `Tss2_Tcti_Device_Init(/dev/tpmrm0)` and fails `243/CREDENTIALS` when no TPM device exists, causing `nixos-rebuild-ng` (now strict, exits 4 on any failed unit) to abort the switch. Local daemon off, `programs.virt-manager` client stays on for remote `qemu+ssh://root@10.8.0.1/system` (mireo, see [[10-Hosts/mireo#libvirt-virt-manager-remote-target-weg-a|mireo libvirt]]).

## Deploy

```bash
nix run .#rebuild
sudo nixos-rebuild switch --flake .#x270
nix run .#deploy-x270
```
